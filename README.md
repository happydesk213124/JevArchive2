# 🏛️ JevArchive 2

RisuAI 장기기억 플러그인. 대화를 **원문 조각 그대로** 간직하고, 답장마다 지금 필요한 조각을 찾아서 **날짜 · 인물 꼬리표**와 함께 넣어요.
인물 · 관계 · 약속 · 비밀도 알아서 정리해서 화면으로 보여 줘요. 글 쓰는 모델 없이 **Jev(고르기만 하는 판단 모델) + 임베딩**만 써요.

2.0부터 이 저장소예요. 1.x는 [JevArchive](https://github.com/happydesk213124/JevArchive)에 그대로 있어요.

## 화면

다크 모드 전용. 폰은 아래 탭 + 아래에서 올라오는 시트, PC는 왼쪽 메뉴 + 오른쪽 서랍.

- **지금** — 이야기 시간(상태창에서 읽음) · 지금 나온 인물 · *이번 답장에 넣은 기억* 카드 · 진행 중인 약속 · 감독 힌트 · 최근 일어난 일
- **인물** — 관계도(끌어서 이동, 두 손가락/휠로 확대). 선 색은 가까움(분홍) / 멀어짐(파랑), 굵기는 함께 나온 횟수. 인물을 누르면 관계 · 만남 기록(언제 · 어디서 · 무엇) · 약속 · 한 일. 이름표 꼬리(`미연_maid_form` · `미연_2`)는 자동으로 합치고, 펼쳐서 분리
- **약속 · 비밀** — 약속은 진행 중 / 끝남. 비밀은 "누가 · 누구 모르게"로 모으고 내용은 스포일러로 가려요(눌러서 보기). 상대가 알게 되면 "드러남"으로 닫혀요
- **기억** — 기억 조각(날짜 · 장소 · 꼬리표) 찾기, 원문 보기, 📌 고정(매번 넣기)
- **설정** — 연결, 기억 넣기(가볍게 · 균형 · 꼼꼼하게), 이야기 기능, 도구, 진단

처음 열면 시작 안내가 나와요. 키 하나 넣고 다음, 다음, 완료.

## 어떻게 동작하나

**도서관처럼 생각하면 쉬워요**

- 대화 하나 = 책 한 권, 조각 = 한 페이지. 짧은 메시지(500자 이하)는 통째로, 긴 답장은 문단 몇 개씩. 원문은 절대 안 바꿔요.
- **정리 (보낸 뒤 뒤에서):** 페이지마다 날짜 · 장소 스티커(상태창)를 붙여요. 동시에 ① 임베딩("말한 사람: 원문") ② Jev 꼬리표를 만들어요. 꼬리표는 종류(사건 · 행동 · 약속 · 비밀 · 사실 · 잡담) · 누가 · 누구랑 · 누구에게 · 무엇 · 어떻게 · 왜 · 모르게 할 사람이에요. Jev는 그 메시지에 나온 이름 · 낱말 · 문장 중에서 **고르기만** 하고, 없으면 비워요.
- **바뀐 정보:** 새 페이지가 옛 페이지를 바꾸면(장소 · 비밀번호 · 계획 …) 옛 페이지에 표시해요. 같은 드문 낱말이 겹치는 것만 Jev에게 물어요. 질문뿐인 페이지("…였지?")는 빼요.
- **꺼내기 (보낼 때):** ① 동시에: 질문 임베딩 + Jev가 **이번 턴 인물**과 **질문 카드** 고르기 (대화에 한 번도 안 나온 인물은 빼요) ② 후보: 그 인물이 나온 페이지(임베딩으로 1차) · 뜻이 가까운 페이지 · 낱말이 겹치는 페이지 · 고른 질문과 뜻이 가까운 페이지 · 막 밀려난 메시지 → 60개 ③ Jev가 20개씩 동시에 "지금 필요해?" 0~3점 (고른 질문의 답이어도 3점), 빠진 게 있으면 낱말 하나로 한 번 더 ④ 높은 페이지와 앞뒤 페이지를 날짜 순으로.
- **질문 카드:** 질문형 메시지("…였지?")는 무엇을 찾을지 분명한데, 평소 롤플 턴은 흐려요. 사람이 써 둔 질문 60장(기본 20 · 장르마다 8) 중 지금 장면에 맞는 걸 Jev가 같은 요청에서 골라요 (가끔 2 · 보통 4 · 자주 6개). 예: 계단을 뛰어오르자 → "하윤이나 지호가 다쳤거나 아픈 곳이 있었나?" 질문은 메인 모델에 안 보내요. 연출 카드 49장은 질문과 이어져 있어서, 감독이 그 연출을 고른 턴엔 그 질문도 같이 써요.
- 맨 위에 짧게: 지금 시간 · 이번 인물 · 인물끼리 관계(만난 횟수 · 처음 · 최근 만남 · 열린 약속 · 숨기는 비밀) · 인물 태그. 나머지 자리는 거의 다 기억 페이지에 써요.
- 줄 모양: `#12 secret 하윤+도현 ∵도현이 다칠까 봐 ⊘미로: 원문…` — 원문에 이미 있는 이름 · 이유는 빼고, "어제" 옆엔 `(=2024-05-02)` 실제 날짜.
- **인물 로어북:** 이번 턴 인물의 이름 · 별명이 키인 로어북을 켜요. 인물이 잘 안 바뀌어서 캐시에도 좋아요.

**보낸 뒤 (이야기, 뒤에서)**

- 메시지 몇 개씩 Jev 1~2번: 새 인물인지, 둘이 가까워졌는지 / 멀어졌는지, 약속이 생겼는지 / 지켜졌는지, 비밀이 생겼는지 / 드러났는지.
- 보내기를 기다리게 하지 않아요. 메인 모델이 답을 쓰는 동안 같이 돌아요. 답장이 온 뒤에는 아무것도 안 해요.

**감독 힌트 (선택, 기본 꺼짐)**

- 이번 턴 인물 고르기와 *같은* Jev 호출에 질문 몇 개를 더 얹어서 템포 · 꺼낼 약속 · 먼저 움직일 인물 · 분위기를 골라요. 호출이 늘지 않아요.
- 메인 모델에게는 "참고용, 사용자 지시가 먼저"라고 붙여서 넣어요.

**연출 카드 (감독 힌트 안에서)**

- 사람이 미리 써 둔 짧은 연출(예: "침묵의 무게", "알리바이의 구멍", "모닥불")을 Jev가 지금 장면에 맞게 *고르기만* 해요. 글은 모델이 만들지 않아요.
- 기본 134장: 기본 30 · 로맨스 24 · 일상 20 · 미스터리 20 · 판타지 20 · 공포 20. 내 카드도 만들고, JSON으로 나눌 수 있어요.
- 고르는 순서: 조건(다른 인물이 있나 · 관계 온도 · 열린 약속 · 최근에 쓴 카드는 쉼) → **장르 자동 맞춤**(Jev가 이 채팅의 장르를 판단) → 임베딩으로 12장 → Jev가 하나 또는 "없음".
- 카드 속 `{char}` `{user}` `{other}`는 이름으로, 조사도 이름에 맞게 바뀌어요(하윤이 / 지호가).
- 빈도: 가끔 / 보통 / 자주. "맞는 게 없다"는 확률이 낮을 때만 넣어요.
- 실제 Jev로 장르가 다른 장면 6개 × 3번: 18번 중 17번 장면에 맞는 카드를 골랐어요(나머지 1번은 "없음").

### 왜 이렇게 만들었나

- **요약 대신 원문.** 요약은 한 번 틀리면 계속 틀려요. 육하원칙으로 다시 쓴 문장도 시험해 봤는데 어색해지고 날짜가 빠져서 점수가 낮았어요. 원문은 다시 읽으면 돼요.
- **꼬리표는 짧게, 찾는 열쇠로.** 원문에 없는 것(그녀가 누군지, 이유, 누구 모르게)만 앞에 붙여요.
- **날짜와 말한 사람.** 페이지마다 실제 날짜, 색인에는 말한 사람 이름. 둘 다 빼고 재 보면 점수가 크게 떨어져요.
- **이야기 정리는 뒤에서.** 보낸 직후 시작하지만 기다리지 않아서 보내기가 느려지지 않아요.

### 기억력 확인

| 시험 | 1.0.21 | **2.0** |
|---|---|---|

| └ 날짜 질문 (63개) | 8% | **75%** |
| V7 장기기억 시나리오 (80턴, 정답 55개, Risu 채팅 범위 2개, 기억에 정답이 들어갔나) | 53/55 | **54/55** |

- LoCoMo 답하기와 채점은 같은 싼 모델(gemini-2.5-flash-lite)로 했어요. 기억 예산 1500토큰에 실제로는 평균 1100토큰쯤 넣었어요.
- 한 번씩 돌린 숫자라 몇 % 흔들릴 수 있어요. 긴 답장 롤플은 세 번 돌려 13 · 13 · 14였어요.

## 저장

- **원문:** Risu 채팅 그대로. 따로 저장하지 않아요.
- **이 기기:** 조각 벡터(조각마다 128바이트)와 기억 꼬리표. 다른 기기에서는 다시 만들어요.
- **세이브 파일:** 설정 + 채팅마다 이야기 장부(인물 · 관계 · 약속 · 고정, 보통 몇 KB).

## 설치

1. [`jevarchive.js`](https://raw.githubusercontent.com/happydesk213124/JevArchive2/main/jevarchive.js)를 받습니다.
2. RisuAI → 설정 → 플러그인 → 플러그인 추가에서 파일을 고릅니다.
3. 플러그인 설정의 **JevArchive**(또는 채팅 화면의 🏛️ 버튼)를 열면 시작 안내가 나와요.
4. Risu 채팅 범위(최대 컨텍스트)를 줄이면 토큰이 줄어요. Risu 자체 메모리(하이파 · 수파)는 꺼 두세요.
5. 이미 긴 채팅이거나 **1.x에서 올라왔으면** 설정 › 정리 › **지금 전부 정리**를 한 번 눌러 주세요. 2.0은 기억을 새 방식으로 다시 만들어요 (원문은 그대로라 잃는 건 없어요).

다른 장기기억 플러그인(HypaJev, JevHypa 등)과 같이 켜면 기억이 두 번 들어가요. 하나만 켜 두세요.

## 자동 업데이트

파일 머리의 `//@update-url`로 RisuAI가 이 저장소 `main`의 새 `//@version`을 감지해요.

1.x는 옛 저장소를 보고 있어서 2.0으로 저절로 넘어오지 않아요. 위 설치대로 한 번 직접 설치하면 그 뒤로는 여기서 업데이트돼요.
